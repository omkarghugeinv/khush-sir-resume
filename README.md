## Tech Stack

This portfolio is built using:
- **[Astro](https://astro.build/)** - Static site generator for fast, modern websites
- **[Tailwind CSS](https://tailwindcss.com/)** - Utility-first CSS framework
- **TypeScript** - For type-safe configuration

## Local Development

If you'd like to run this project locally on your machine, follow these steps:

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the local Astro development server:
   ```bash
   npm run dev
   ```
4. Open your browser to the local address provided (usually `http://localhost:4321`)
